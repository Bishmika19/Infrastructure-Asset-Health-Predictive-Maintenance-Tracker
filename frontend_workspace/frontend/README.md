# Frontend

React 18 + TypeScript + Vite UI for the Infrastructure Asset Health & Predictive Maintenance Tracker.
The app runs on its own with a built-in asset dataset; it makes no backend or database calls.

- Install: `npm install`
- Dev server: `npm run dev -- --host 0.0.0.0 --port 3000`
- Build: `npm run build`; Lint: `npm run lint`; Test: `npm test`

## Sign-in accounts

| Role | Username | Password |
| --- | --- | --- |
| Asset Manager | `asset manager` | `asset manager` |
| Maintenance Crew | `maintenance crew` | `maintenance crew` |

Usernames are not case-sensitive; passwords must match exactly.
